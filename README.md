# Adventure Game

Unity editor version: **6000.3.17f1**.

## Open the project

1. Clone this repository with GitHub Desktop or Git.
2. In Unity Hub, choose **Add > Add project from disk**.
3. Select the **AdventureGameSGD168** folder inside this repository.
4. Open **Assets/Scenes/Start Scene.unity** in Unity.

The Git repository is `AdventureGame/`; the Unity project is the nested
`AdventureGame/AdventureGameSGD168/` folder. The repository root is not the Unity project.

## Version control

Share the Unity project's `Assets` (including `.meta` files), `Packages`, and
`ProjectSettings` folders. The ignore rules exclude generated caches, temporary
files, local editor preferences, and local IDE configuration.
